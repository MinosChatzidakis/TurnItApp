A web app which allows users to create or join a session with others and suggest songs to play at a party/function etc. They can vote for songs that have already been suggested, and the host has complete control over the songs played, the banned songs, and the users who have joined.

React frontend with a node.js backend and a mongodb database. Made use of RESTful APIs, token validation, expiration and storage as well as implemented security practices to ensure an unauthorised user cannot have augmented privileges.
